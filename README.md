# DNS Manager для Windows
Сборка exe: загрузите папку на GitHub -> Actions -> build-exe -> скачайте DnsManager.exe (запрашивает права администратора).
Без сборки: установите Python 3 и запустите от администратора: python dns_manager.py
Если интернет пропал после аварийного закрытия: DnsManager.exe --restore
