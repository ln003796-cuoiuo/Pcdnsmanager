# Local AI (Android)

Офлайн-чат с реальной LLM на телефоне (Google MediaPipe LLM Inference, например Gemma).
"Обучение" txt-файлами: кнопка «+ txt (обучить)» добавляет файлы в локальную базу знаний.
При каждом вопросе приложение находит самые подходящие фрагменты (TF-IDF) и подаёт их модели как контекст.
Знания сохраняются между запусками, «Очистить» стирает их.

## Сборка APK через GitHub
1. Залей содержимое папки в репозиторий.
2. Actions → Build APK → скачай артефакт LocalAI-apk (app-debug.apk).

## Модели (без лицензии, без входа)
Qwen2.5 0.5B: `litert-community/Qwen2.5-0.5B-Instruct`, файл `Qwen2.5-0.5B-Instruct_multi-prefill-seq_q8_ekv1280.task`.
Шаблон чата подбирается автоматически по имени файла (qwen -> ChatML, иначе Gemma).

## Модель
Выбирается в приложении (кнопка «Модель»), формат MediaPipe `.task`/`.bin`,
например Gemma 3 1B int4 (Hugging Face: litert-community/Gemma3-1B-IT, нужно принять лицензию).

Требования: Android 8+, arm64, желательно 6+ ГБ ОЗУ.

## Про настоящее дообучение
Менять веса модели на телефоне нереально. Если нужно именно дообучение (LoRA) на твоих txt,
делается на ПК/Colab, затем модель конвертируется в .task и грузится в приложение.
